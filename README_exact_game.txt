PARI — «Как закончится гейм» (порт 5001)

Файлы:
1) pari_exact_game_analyzer_v1.py — сбор live-данных, прогноз 8 исходов, статистика SQLite.
2) app_exact_game.py — веб-интерфейс http://127.0.0.1:5001/
3) exact_game_live.json — текущие живые прогнозы (создаётся/обновляется анализатором).

Запуск в PyCharm:
- запустить pari_exact_game_analyzer_v1.py
- отдельно запустить app_exact_game.py
- открыть http://127.0.0.1:5001/

Деус-проект на http://127.0.0.1:5000/ не меняется и использует свою БД.
Новый проект использует отдельную БД pari_exact_game_stats.sqlite3.

Честная статистика:
- новый прогноз создаётся только при счёте 0:0;
- если скрипт впервые увидел гейм уже после первого очка, этот гейм не считается;
- если точный итог нельзя восстановить из sportscast, записывается UNKNOWN, а не ошибка;
- тай-брейки с game_num >= 13 не прогнозируются как обычный гейм;
- сырые события матчей не сохраняются; максимум 30 диагностических UNKNOWN-примеров.

Исходы:
40:0, 40:15, 40:30, +:40, 0:40, 15:40, 30:40, 40:+
+:40 = первый игрок выиграл гейм после деуса
40:+ = второй игрок выиграл гейм после деуса

Статистика на странице:
- TOP-1 — модель угадала точный исход из 8;
- TOP-2 — реальный исход оказался среди двух самых вероятных прогнозов;
- по каждому исходу сравниваются средняя вероятность модели и фактическая частота.
